# Pół Drogi — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full-stack MVP, który dla grupy osób startujących z różnych miejsc i różnymi środkami transportu proponuje sprawiedliwe miejsce spotkania (minimax), z importem uczestników z czatu przez AI i generowaniem zaproszenia.

**Architecture:** Backend FastAPI w warstwach `api → services → domain/adapters → db`; adaptery usług zewnętrznych za interfejsami `Protocol` z fallbackami; wszystkie zależności wstrzykiwane przez `Container`, podmieniany w testach na atrapy. Frontend React + TS z TanStack Query, typy generowane z OpenAPI.

**Tech Stack:** Python ≥ 3.12, FastAPI, SQLModel/SQLite, httpx, pydantic-settings, google-genai, anthropic, pytest, ruff · React 18, TypeScript strict, Vite, Tailwind CSS 3, React Router 6, TanStack Query 5, react-leaflet 4, Vitest, Testing Library, openapi-typescript · Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-15-pol-drogi-design.md` — czytaj razem z tym planem.

## Global Constraints

- Prefiks API: `/api/v1`. Swagger pod `/docs`, schemat pod `/openapi.json`.
- Format każdego błędu: `{"error": {"code": str, "message": str, "details": any|null}}`; komunikaty `message` po polsku.
- Statusy: `404` brak zasobu, `409` reguła biznesowa, `422` walidacja / `address_not_found` / < 2 uczestników, `502 ai_bad_output`, `503 ai_unavailable` lub niedostępna usługa.
- CORS: originy z `CORS_ORIGINS` (lista po przecinku), domyślnie `http://localhost:5173`; nigdy `*`.
- Maks. 10 uczestników na spotkanie; `title` 1–100 znaków; `name` 1–50; `start_label` 1–200; `invite_message` ≤ 1000; tekst do AI 1–2000; zaproszenie od AI ≤ 600.
- Czas: API przyjmuje i zwraca ISO 8601 **z offsetem**; baza przechowuje UTC; tekst zaproszenia formatuje godziny w strefie `Europe/Warsaw`.
- Wszystkie wywołania HTTP: timeout 8 s, jedna ponowna próba przy 429/5xx — **poza Nominatim** (bez ponowień).
- Nominatim: globalnie maks. 1 zapytanie/s, nagłówek `User-Agent` = `OSM_USER_AGENT`, `countrycodes=pl`, `viewbox=18.40,54.60,18.80,54.30`, `bounded=0`, brak autouzupełniania.
- OSRM: `https://routing.openstreetmap.de/routed-{foot|bike|car}/table/v1/driving/{lon,lat;...}?sources=..&destinations=..&annotations=duration`.
- Overpass: endpointy `https://overpass-api.de/api/interpreter`, `https://overpass.private.coffee/api/interpreter` (w tej kolejności).
- Prędkości szacunkowe (odległość w linii prostej × 1,3): pieszo 4,8 km/h, rower 15 km/h, auto 30 km/h. Komunikacja: 5 + 5 min + (linia prosta × 1,4) / 22 km/h, nigdy więcej niż pieszo.
- Prefiltr: 25 kandydatów; Overpass maks. 300 obiektów z nazwą; `limit` sugestii 1–10, domyślnie 5; cache sugestii TTL 600 s.
- Obszar poszukiwań: prostokąt uczestników poszerzony z każdej strony o `max(1 km, 15% rozpiętości)`.
- AI nigdy nie zapisuje do bazy; żadna liczba pokazywana użytkownikowi nie pochodzi z modelu.
- `LLM_PROVIDER = gemini | claude | none`; brak klucza wybranego dostawcy ⇒ efektywnie `none`.
- Atrybucja „© OpenStreetMap contributors” na mapie i przy snapshocie lokali.
- Każdy commit kończy się stopką:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```

## Review Focus

1. **Polskie znaki w adresach i imionach** („Gdańsk Wrzeszcz”, „Łukasz”) — muszą przejść przez geokodowanie, bazę, AI i JSON bez zniekształceń. Test: Task 4 `test_geocode_query_keeps_polish_characters`, Task 2 `test_meetup_title_with_polish_characters_roundtrips`.
2. **Uczestnicy w tym samym miejscu** (zerowa rozpiętość prostokąta) — obszar musi się poszerzyć o 1 km, a ranking nie może dzielić przez zero. Test: Task 3 `test_search_bbox_degenerate_points_expands_by_1km`, `test_rank_all_zero_times`.
3. **Termin spotkania a strefa czasowa** — użytkownik wpisuje 18:00 w Polsce; zaproszenie musi pokazać godziny wyjścia w czasie polskim, także przez zmianę czasu letni/zimowy. Test: Task 9 `test_departure_lines_use_warsaw_time`.
4. **AI zwraca pustą listę albo więcej niż 10 osób** (tekst bez ludzi, długi czat) — pusta lista to poprawny szkic z wypełnionym `unparsed`; > 10 osób ⇒ szkic obcięty do 10 z ostrzeżeniem w `unparsed`. Test: Task 8 `test_parse_empty_result_is_valid_draft`, `test_parse_truncates_to_ten`.
5. **Zmiana uczestników po wyliczeniu sugestii** — cache nie może zwrócić rankingu dla starego składu. Test: Task 6 `test_cache_invalidated_by_participant_change`.
